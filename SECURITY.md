# Security policy

## Supported versions

Only the latest release on
[Nexus Mods](https://www.nexusmods.com/starfield/mods/16493) and the `main` branch of this
repository are supported.

## Reporting a vulnerability

If you find a security issue in this plugin (for example arbitrary code execution via
crafted game data, or unsafe handling of paths/logs), **do not** open a public issue.

Contact the maintainer privately via GitHub:
[@pjmagee](https://github.com/pjmagee).

Please include enough detail to reproduce the problem. We will acknowledge the report when
possible and work on a fix before any public disclosure.
